В работе по данным 649 школьников предсказывается итоговая оценка в процентах. Модель — `LinearRegression`. Исходные файлы лежат в папке `task/`.

## Что происходит в ноутбуке

1. **Подготовка данных.** В `data.csv` два признака склеены в один столбец. Знак числа показывает, планирует ли ученик поступать в университет, последняя цифра — число прошлых неудач:

   ```python
   joined = data["plans_universitypast_failures"]
   data["plans_university"] = np.sign(joined)
   data["past_failures"] = joined.abs() % 10
   data = data.drop(columns="plans_universitypast_failures")
   ```

   Затем 17 пропусков заменяются средними по столбцам, а признаки нормализуются.

2. **Обучение и проверка.** Начиная с задания 4 качество считается на четырёх перемешанных частях данных, как указано в условии. Для каждого этапа выводятся R² и MAE:

   ```python
   folds = KFold(n_splits=4, shuffle=True, random_state=42)
   r2 = cross_val_score(LinearRegression(), data_normalized, scores,
                        cv=folds, scoring="r2")
   ```

3. **Дополнительные признаки и исправления.** Из `attendance.csv` берётся число посещённых занятий, из `school_support.txt` — признак материальной поддержки. Затем годы рождения в `age` переводятся в возраст, минуты в `traveltime` — в категории, а пять оценок, записанных как доли, — в проценты. Для поиска ошибок строятся гистограммы. Там, где способ отдельного обучения не задан, используется разделение 70% на обучение и 30% на проверку.
